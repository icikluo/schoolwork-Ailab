# 🥗 食谱搭配

一个**纯网页**的食谱搭配工具：填身体数据算出每日目标卡路里，记录今天吃了什么，系统按剩余额度自动推荐下一餐。

**不需要安装任何东西**，双击就能用。

## 快速开始

1. 打开文件夹 `自选作品`。
2. 双击 **`index.html`**，用 Chrome / Edge 打开。
3. 在「① 设置每日目标」里填好数据，点「计算目标」。
4. 从「全部食谱」里点 **记录**，开始今天的打卡。

## 功能

| 功能 | 说明 |
|---|---|
| 每日目标卡路里 | 三步公式：基础代谢 → 乘活动系数 → 按人群调整，结果取整到 10，低于 1200 自动上调 |
| 今日记录 | 点「记录」加入今天，实时累加卡路里、碳水、脂肪、膳食纤维、蛋白质 |
| 进度条 | 显示今日摄入占目标的比例，超出目标变红 |
| 自动推荐 | 按人群 + 剩余额度推荐 3 道今天还没吃过的菜 |
| 人群 | 减脂 / 增肌 / 控糖 / 均衡 四类 |

记录保存在浏览器本地（localStorage），关掉网页再打开还在。点「清空今日记录」可清零。

## 项目结构

```
自选作品/
├── index.html          页面结构
├── 样式.css             白蓝配色样式
├── 脚本.js              全部逻辑（目标计算 / 记录 / 推荐 / 渲染）
├── PRD.md              需求文档（含三不原则、字段契约）
├── README.md           本文件
├── 数据/
│   ├── foods.json      食谱原始数据（24 条）
│   └── 食谱.js          同上数据的 JS 版本，供网页直接加载
└── 测试/
    ├── 核对数据.py      校验 24 条食谱是否符合字段契约
    └── 逻辑复算.py      复算卡路里公式与汇总逻辑（21 项测试）
```

## 跑测试

装了 Python 3 的话：

```bash
cd 自选作品
python 测试/核对数据.py
python 测试/逻辑复算.py
```

两个脚本全绿表示数据与公式都正常。

## 怎么改

- **加一道菜**：在 `数据/foods.json` 末尾按同样字段加一条，再同步到 `数据/食谱.js`。
- **改人群系数**：`脚本.js` 顶部的 `人群系数`，比如把减脂从 `0.8` 改到 `0.7`。
- **改推荐数量**：`脚本.js` 顶部的 `推荐数量`（默认 3）。
- **改配色**：`样式.css` 顶部的 `:root` 变量。

## 已知限制

- 营养数据为教学用估算值，**不构成医学或营养建议**。
- 只保存当天记录，不保留历史。
- 推荐不考虑口味、过敏原、烹饪时间。

## 三不原则（当前版本不做）

1. 不做账号注册、云端同步、多用户。
2. 不调用在线营养数据库 API，不让 AI 生成食谱。
3. 不做一周 / 一月计划的自动优化算法。

详见 `PRD.md` 第六节。
