# 🥗 食谱搭配

一个**纯网页**的饮食管理工具：填身体数据算出每日目标卡路里与宏量营养目标，记录今天吃了什么，系统按剩余额度自动推荐下一餐，还能生成一周计划并一键「标记已吃」。另设训练分区，按部位提供健身动作教程。

**不需要安装任何东西，双击就能用，全部功能断网可用。**

**v0.5 起改成「一页一功能区」：6 个 HTML 共用左侧常驻导航栏，点一下就到对应功能区；
相关功能合并放在同一页（今日摄入 + 为你推荐、今日记录 + 近 7 天）。**

## 快速开始

1. 打开文件夹 `自选作品`，双击 **`index.html`**（入口页「今日总览」），用 Chrome / Edge 打开。
2. 左侧导航栏常驻，点任意一项进入对应页面，当前页会高亮。

| 想做什么 | 点侧栏 |
|---|---|
| 看今天吃了多少、下一餐推荐什么 | 今日总览 |
| 填身体数据算每日目标 | 我的目标 |
| 找菜、看做法、记录一餐 | 食谱专区 |
| 排 7 天三餐 | 一周计划 |
| 移除记录、回看近 7 天 | 记录与回看 |
| 查健身动作要点 | 动作库 |

3. 第一次用先去「我的目标」填身体数据，之后每页顶栏、侧栏都会显示目标 kcal 与「今日 N 道 · X kcal」。
4. 在「食谱专区」或「为你推荐」点 **记录**，侧栏的今日计数会立即变化；点 **做法** 看食材与步骤。

## 功能

| 功能 | 说明 |
|---|---|
| 每日目标卡路里 | 三步公式：基础代谢 → 乘活动系数 → 按人群调整，结果取整到 10，低于 1200 自动上调 |
| 宏量营养目标 | 按人群供能比换算蛋白质 / 脂肪 / 碳水三项目标（借鉴 CookHero 目标管理） |
| 今日记录 | 点「记录」加入今天，自动按时间归入 早 / 午 / 晚 / 加餐 餐次 |
| 进度条 | 显示今日摄入占目标的比例，超出目标变红 |
| 自动推荐 | 按人群 + 剩余额度推荐 3 道今天还没吃过的菜；「换一批」在同一排序里往后翻 3 道，到尾回绕 |
| 份量支持 | 记录时可选整份 / 半份，营养按比例折算（半份在记录里带标注） |
| **食谱专区** | 按 全部 / 减脂 / 增肌 / 控糖 / 均衡 分区浏览 40 道食谱卡片；支持菜名搜索与热量排序，分区选择会记住；默认显示 12 道，点「显示全部」展开（搜索/排序时自动全量）；点「做法」展开食材与步骤 |
| **近 7 天记录** | 换天自动结转，左栏「近 7 天」标签可回看最近 7 天的记录明细（纯文字，不做图表） |
| **一周计划** | 生成连续 7 天的三餐安排；第 1 天（今天）可一键「标记已吃」转入今日记录 |
| **偏差分析** | 生成计划后用一句话说明「今天计划 vs 实际记录」的偏差（只做文字，不做图表） |
| **训练分区** | 30 个健身动作教程（v0.4.2 扩充），按 上肢 / 下肢 / 核心 / 全身 分区，每卡带器械标签（自重 / 哑铃 / 壶铃 / 杠铃 / 健身房器械） |
| 人群 | 减脂 / 增肌 / 控糖 / 均衡 四类 |

记录与计划都保存在浏览器本地（localStorage），关掉网页再打开还在。


## 怎么改

- **加一道菜**：在 `数据/foods.json` 末尾按同样字段加一条（含 食材 / 步骤），再同步到 `数据/食谱.js`。
- **改人群系数**：`脚本.js` 顶部的 `人群系数`，比如把减脂从 `0.8` 改到 `0.7`。
- **改宏量供能比**：`脚本.js` 顶部的 `宏量供能比`（各人群三项之和须为 1）。
- **改推荐数量**：`脚本.js` 顶部的 `推荐数量`（默认 3）。
- **改计划天数**：`脚本.js` 顶部的 `计划天数`（默认 7，**不要改成 30**，见三不原则第 3 条）。
- **改配色**：`样式.css` 顶部的 `:root` 变量。
- **改侧栏导航**：7 个 HTML 里的 `<aside class="侧栏">` 需同步修改；
  `测试/检查契约.py` 会校验所有页面的导航项是否完全一致。
- **改养成页外观**：`养成.html` 是 `工具/生成养成页.py` 装配出来的（渲染器来自
  `测试/真房间合成.html`）。要改渲染逻辑就改验证页再重新装配，别直接改养成.html。
- **加一个页面**：复制任一 HTML → 改 `<body data-页面="…">` → 在 `脚本.js` 的 `渲染当前页()` 加分支
  → 侧栏加一项 → 跑 `检查契约.py`。

## 已知限制

- 营养数据为教学用估算值，**不构成医学或营养建议**。
- 历史记录只保留最近 7 天的纯文字回看，不做更长历史与图表。
- 养成页要读 38MB 模型，第一次打开有明显等待（软件渲染下约 10 秒），之后走浏览器缓存。
- 换装目前只能改颜色：模型是单一融合网格，衣服烘在贴图里，换款式需要单独的低模服装包。
- 推荐不考虑口味、过敏原、烹饪时间。
- 一周计划为固定 7 天，不可调整；30 天计划属当前范围外。
- 全部功能离线可用，不调用任何在线接口（v0.3 曾设可选 AI 助手，v0.4 已移除）。
- 页面之间是整页跳转（本地文件，瞬间打开），不做无刷新的 SPA 切换；
  记录、目标、计划通过 localStorage 在 6 个页面间共享。
- 食谱配图已本地化到 `数据/图片/`，断网可显示。
  其中 r001–r024 来自 Unsplash（遵循 Unsplash License）与课程专用素材；
  r025–r040 共 16 张为 AI 生成配图，菜品做法参考
  《减脂饮食全书》（github.com/da-damu/fat-loss-diet-book）。
- 训练动作（v0.4.2 扩至 28 个）的步骤要点参考
  [exercises-dataset-zh](https://github.com/Devillmy/exercises-dataset-zh)
  （MIT License）的中文说明提炼改写；新增 14 张动作配图为 AI 生成。

## 三不原则（当前版本不做）

1. 不做账号注册、云端同步、多用户。
2. 不做花哨的可视化图表（环形图、趋势曲线等）。
3. 不做一个月（30 天）的食谱计划。

详见 `文档/PRD.md` 第六节。
