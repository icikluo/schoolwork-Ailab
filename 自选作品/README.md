# 🐱 桌宠 Desktop Pet

一个用 **Python 自带标准库** 写成的桌面宠物，无需安装任何第三方库。它是一只可爱的小橘猫，会自己**吃饭、唱歌、睡觉、散步**，还能被**摸头**、**分身**、**拖拽**。

## 怎么运行

1. 电脑上装好 Python 3（[官方下载](https://www.python.org/downloads/)），安装时勾选 **Add python.exe to PATH**。
2. 双击 **`启动桌宠.bat`**，桌宠就出现在桌面上啦。
   - 或在命令行：`python desktoppet_launcher.py`
   - 想一次开多只：`python desktoppet_launcher.py -multi 3`

> 说明：本程序只用 Python 自带的 `tkinter`（画图形、做窗口），**不需要**安装任何额外库。

## 玩法

| 操作 | 效果 |
| --- | --- |
| **左键单击一次** | 摸头！小橘猫会开心地弹起来、闭眼笑、冒♥，还会说话 |
| **左键快速连点 3 次** | 分身！在附近复制出一只新的桌宠 |
| **按住左键拖动** | 拖着桌宠满屏幕跑 |
| **右键** | 弹出菜单，可退出这一只桌宠 |
| **鼠标悬停在桌宠身上** | 桌宠右侧出现选项面板：**隐藏**、**关闭** |
| **隐藏** | 收进屏幕右下角的一颗迷你猫头小图标，点击即可唤回 |
| **关闭** | 彻底退出这一只桌宠 |
| **分身合并** | 把任何一只分身**拖到本体身上（靠得很近）**，分身会自动并入本体，合并回一只 |

**自主行为**（不用管，它自己会做）：
🍜 吃饭、♪ 唱歌跳舞、😴 睡觉、🚶 散步、发呆。

> 如何区分“单击摸头”和“点3次分身”：在 **0.65 秒内** 连点才算“多次点击”。所以单击摸头、快速点三下分身，各不干扰，也不会误触。

## 改成你自己的形象

默认形象是程序用 `tkinter` 画的。想换成自己的图片（比如你给的那张桌宠照片）：

1. 在 `sprites/` 目录放入你的 PNG（**建议保留透明背景**），起名如：
   - `sprites/idle.png`　站立/发呆
   - `sprites/mopping.png`　摸头
   - `sprites/eating.png`　吃饭
   - `sprites/singing.png`　唱歌
   - `sprites/sleeping.png`　睡觉
2. 在 `pet_config.py` 里把 `USE_IMAGE = False` 改成 `USE_IMAGE = True`（并可选 `IMAGE_PATH`）。
3. 重新运行。

> 若你的素材没有做 5 个状态，只放一张 `idle.png` 也行，程序会自动在所有状态复用同一张图（会用弹跳/缩放/翻转做出简单动画效果）。

## 想微调？

- **外形/配色/尺寸**：改 `pet_config.py` 顶部的颜色和 `PET_SIZE`。
- **动作节奏**：改 `pet_config.py` 里的 `STATE_TIMINGS`。
- **点击灵敏度**：改 `CLICK_WINDOW_SECS`、`DRAG_DEAD_ZONE`。

## 常见问题

- **桌宠后置/被其他窗口挡住**：它是置顶的，正常情况下一直浮在最前。若被挡说明被其他置顶程序覆盖，点一下它即可。
- **透明处发黑**：`SB_BG`（默认深紫色）是“真正透明”的标记色，别把它当 fg 用到可见图形上。见到发黑通常是把文字/图形画成了这个颜色。
- **点击没反应**：先移动一下鼠标再点，或等半秒——避免误把“刚落下就开始的拖拽”当成点击。
