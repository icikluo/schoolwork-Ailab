# 🥗 食谱搭配

一个**纯网页**的食谱搭配工具：填身体数据算出每日目标卡路里，记录今天吃了什么，系统按剩余额度自动推荐下一餐。

**不需要安装任何东西**，双击就能用。

## 快速开始

1. 打开文件夹 `自选作品`。
2. 双击 **`index.html`**，用 Chrome / Edge 打开。
3. 在「① 设置每日目标」里填好数据，点「计算目标」。
4. 从「全部食谱」里点 **记录**，开始今天的打卡。

## 功能

| 功能 | 说明 |
|---|---|
| 每日目标卡路里 | 三步公式：基础代谢 → 乘活动系数 → 按人群调整，结果取整到 10，低于 1200 自动上调 |
| 今日记录 | 点「记录」加入今天，实时累加卡路里、碳水、脂肪、膳食纤维、蛋白质 |
| 进度条 | 显示今日摄入占目标的比例，超出目标变红 |
| 自动推荐 | 按人群 + 剩余额度推荐 3 道今天还没吃过的菜 |
| **食谱专区** | 按 全部 / 减脂 / 增肌 / 控糖 / 均衡 分区浏览全部食谱卡片 |
| **一周计划** | 生成连续 7 天的三餐安排，逐日扣减额度，同一天不重复 |
| 人群 | 减脂 / 增肌 / 控糖 / 均衡 四类 |

记录与计划都保存在浏览器本地（localStorage），关掉网页再打开还在。

## 跑测试

装了 Python 3 的话：

```bash
cd 自选作品
python 测试/核对数据.py     # 校验 24 条食谱字段契约
python 测试/逻辑复算.py     # 40 项：公式 / 汇总 / 推荐 / 一周计划
python 测试/检查语法.py     # JS 括号配对
python 测试/检查契约.py     # HTML id 与 JS 引用是否一致
```

四个脚本全绿表示数据、公式与页面契约都正常。

## 怎么改

- **加一道菜**：在 `数据/foods.json` 末尾按同样字段加一条，再同步到 `数据/食谱.js`。
- **改人群系数**：`脚本.js` 顶部的 `人群系数`，比如把减脂从 `0.8` 改到 `0.7`。
- **改推荐数量**：`脚本.js` 顶部的 `推荐数量`（默认 3）。
- **改计划天数**：`脚本.js` 顶部的 `计划天数`（默认 7，**不要改成 30**，见三不原则第 3 条）。
- **改配色**：`样式.css` 顶部的 `:root` 变量。

## 已知限制

- 营养数据为教学用估算值，**不构成医学或营养建议**。
- 只保存当天记录，不保留历史。
- 推荐不考虑口味、过敏原、烹饪时间。
- 一周计划为固定 7 天，不可调整；30 天计划属当前范围外。
- 食谱配图尚未补齐，没有图片时显示带菜名的占位块。

## 三不原则（当前版本不做）

1. 不做账号注册、云端同步、多用户。
2. 不做花哨的可视化图表（环形图、趋势曲线等）。
3. 不做一个月（30 天）的食谱计划。

详见 `PRD.md` 第六节。
