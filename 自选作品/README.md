# 🥗 食谱搭配

一个**纯网页**的饮食管理工具：填身体数据算出每日目标卡路里与宏量营养目标，记录今天吃了什么，系统按剩余额度自动推荐下一餐，还能生成一周计划并一键「标记已吃」。另设训练分区，按部位提供健身动作教程。

**不需要安装任何东西**，双击就能用，断网也能完整使用。

## 快速开始

1. 打开文件夹 `自选作品`。
2. 双击 **`index.html`**，用 Chrome / Edge 打开。
3. 在「① 设置每日目标」里填好数据，点「计算目标」。
4. 从「全部食谱」里点 **记录**，开始今天的打卡；点 **做法** 可查看食材与步骤。

## 功能

| 功能 | 说明 |
|---|---|
| 每日目标卡路里 | 三步公式：基础代谢 → 乘活动系数 → 按人群调整，结果取整到 10，低于 1200 自动上调 |
| 宏量营养目标 | 按人群供能比换算蛋白质 / 脂肪 / 碳水三项目标（借鉴 CookHero 目标管理） |
| 今日记录 | 点「记录」加入今天，自动按时间归入 早 / 午 / 晚 / 加餐 餐次 |
| 进度条 | 显示今日摄入占目标的比例，超出目标变红 |
| 自动推荐 | 按人群 + 剩余额度推荐 3 道今天还没吃过的菜 |
| **食谱专区** | 按 全部 / 减脂 / 增肌 / 控糖 / 均衡 分区浏览 40 道食谱卡片，点「做法」展开食材与步骤 |
| **一周计划** | 生成连续 7 天的三餐安排；第 1 天（今天）可一键「标记已吃」转入今日记录 |
| **偏差分析** | 生成计划后用一句话说明「今天计划 vs 实际记录」的偏差（只做文字，不做图表） |
| **训练分区** | 14 个健身动作教程，按 上肢 / 下肢 / 核心 / 全身 分区 |
| 人群 | 减脂 / 增肌 / 控糖 / 均衡 四类 |

记录与计划都保存在浏览器本地（localStorage），关掉网页再打开还在。

## 怎么改

- **加一道菜**：在 `数据/foods.json` 末尾按同样字段加一条（含 食材 / 步骤），再同步到 `数据/食谱.js`。
- **改人群系数**：`脚本.js` 顶部的 `人群系数`，比如把减脂从 `0.8` 改到 `0.7`。
- **改宏量供能比**：`脚本.js` 顶部的 `宏量供能比`（各人群三项之和须为 1）。
- **改推荐数量**：`脚本.js` 顶部的 `推荐数量`（默认 3）。
- **改计划天数**：`脚本.js` 顶部的 `计划天数`（默认 7，**不要改成 30**，见三不原则第 3 条）。
- **改配色**：`样式.css` 顶部的 `:root` 变量。

## 已知限制

- 营养数据为教学用估算值，**不构成医学或营养建议**。
- 只保存当天记录，不保留历史。
- 推荐不考虑口味、过敏原、烹饪时间。
- 一周计划为固定 7 天，不可调整；30 天计划属当前范围外。
- 食谱配图已本地化到 `数据/图片/`，断网可显示。
  其中 r001–r024 来自 Unsplash（遵循 Unsplash License）与课程专用素材；
  r025–r040 共 16 张为 AI 生成配图，菜品做法参考
  《减脂饮食全书》（github.com/da-damu/fat-loss-diet-book）。

## 三不原则（当前版本不做）

1. 不做账号注册、云端同步、多用户。
2. 不做花哨的可视化图表（环形图、趋势曲线等）。
3. 不做一个月（30 天）的食谱计划。

详见 `PRD.md` 第六节。
