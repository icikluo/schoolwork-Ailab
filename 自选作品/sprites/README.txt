# sprites（桌宠形象图片目录）

把你想用的桌宠 PNG 图片放到这里，程序就能用它替换默认的小橘猫。

**支持的图片（按文件名识别）：**

| 文件名 | 用途 |
| --- | --- |
| `idle.png` | 站立 / 发呆（必填，作为兜底） |
| `mopping.png` | 被摸头时 |
| `eating.png` | 吃饭时 |
| `singing.png` | 唱歌时 |
| `sleeping.png` | 睡觉时 |
| `walking.png` | 散步时（不提供则用 idle.png） |

**参数：**
- 建议透明背景（.png）。
- 尺寸会自动缩放到画布内（约 200×180 内），不必严格匹配。
- 只提供一张 `idle.png` 也可以，其它状态会自动复用同一张图并加上轻微浮动动画。

**启用方法：**
打开 `pet_config.py`，把 `USE_IMAGE = False` 改成 `USE_IMAGE = True`，重新启动桌宠即可。

如果你只有一张主图、不想逐个命名，也可以把该图写在 `IMAGE_PATH` 里（指向某个 png 文件）。
