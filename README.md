## 一、本学期自选作品

### 🥗 食谱搭配（网页版）

一个按人群推荐、可记录每日饮食的食谱工具。**纯前端、零依赖，双击就能跑，全部功能断网可用。**

**运行方式**

```bash
# 方式一：直接双击
自选作品/index.html

# 方式二：在文件管理器里打开
D:\lab\自选作品\index.html
```

不需要安装 Node.js、不需要 npm install，也不需要联网。

**主要功能**

| 功能 | 说明 |
|---|---|
| 每日目标卡路里 | 三步公式（基础代谢 → 活动系数 → 人群调整），结果取整到 10，低于 1200 自动上调 |
| 宏量营养目标 | 按人群供能比换算蛋白质 / 脂肪 / 碳水三项目标 |
| 今日记录 | 点「记录」加入当天，自动归入 早/午/晚/加餐 餐次，实时累加五类营养 |
| 自动推荐 | 按人群 + 剩余额度推荐 3 道今天还没吃过的菜 |
| 食谱专区 | 按 减脂 / 增肌 / 控糖 / 均衡 分区浏览 40 道菜，每条带配图，点「做法」看食材与步骤 |
| 一周计划 | 生成连续 7 天的三餐安排，今天的一餐可一键「标记已吃」转入记录，附偏差分析 |
| 训练分区 | 14 个健身动作教程，按上肢 / 下肢 / 核心 / 全身分区 |

## 五、三不原则（当前版本 v0.1 绝不做的三件事）

1. **不做**账号注册、云端同步、多用户。
2. **不做**花哨的可视化图表（环形图、趋势曲线等）。
3. **不做**一个月（30 天）的食谱计划。

详见 [`自选作品/PRD.md`](./自选作品/PRD.md) 第六节。

> 三不原则是当前版本的边界，不是永久禁令。
> 需要放开时走 `PRD.md` 第六之二节规定的范围变更流程（Issue → 影响面分析 → 验收标准 → 记录）。

## 六、已知限制

- 营养数据为教学用估算值，**不构成医学或营养建议**。
- 只保存当天记录，不保留历史。
- 一周计划固定 7 天，不提供 30 天。
- 全部功能离线可用（v0.3 曾设可选 AI 助手，v0.4 已移除）。
- 需在被现代浏览器打开（Chrome / Edge），不支持 IE。

## 七、开发说明

本项目的开发过程遵循课程要求的「5 阶段人机协同证据链」：

```
意图声明 → AI 方案 → 人类审查 → Git 差异与测试 → 决策归档
```

具体体现：

- 每一条提交只做一件事，提交信息写清「问题 / 原因 / 修复 / 验证」
- 所有功能改动都伴随测试更新
- 个人手工改动与参数实验留有完整记录（见 `作业/A1/`）
